# Voidrender Tap

## How do I install these formulae?

`brew install voidrender/tap/<formula>`

Or `brew tap voidrender/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "voidrender/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
